# Homotopy Groups of Configuration Spaces

Yili Wen, UChicago Math REU 2025

An expository paper on the Fadell-Neuwirth fibration theorem, showing that configuration spaces of points on punctured closed surfaces are aspherical (K(pi, 1)) spaces, and proving that the classical braid group is isomorphic to the Artin braid group.
